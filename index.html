Practical Development

Lime is a flexible, lightweight layer for Haxe cross-platform developers. It provides windows and the application life cycle, input, rendering, audio, networking and assets, on native and web targets alike. It is also the foundation of OpenFL.

Install

With Haxe installed, run these commands to install Lime and try a sample:

haxelib install lime
haxelib run lime setup
lime create SimpleImage
cd SimpleImage
lime test html5

Read the full setup guide

Targets

  • macOS
  • Linux

  • HTML5
  • WebAssembly
  • Electron
  • HashLink
  • Neko
  • Adobe AIR
  • Flash

Single Codebase

Write in the expressive Haxe programming language, then compile to native C++, JavaScript and other technologies.

Powerful Tooling

Lime's command-line tools create, build, package and run your project for each target, so one command takes it from source to a running application.

Open Source

Everything from the tools to the runtime, and the Haxe language itself, is open source, so Lime is simple to extend or customize.
